# About

I am Sreenidhi, and this site is my working notebook for technical ideas I want to keep sharp: Linux administration, infrastructure, developer workflows, security basics, and the practical debugging details that tend to matter when systems are real.

My goal for this blog is to publish notes that are useful beyond the moment I needed them. A good post here should explain the problem, the environment, the decision points, and the final commands clearly enough that another engineer can adapt the approach.

## Current Focus

- Linux and remote development environments
- Secure access, SSH, and operational hygiene
- Infrastructure setup notes that include context and troubleshooting
- Turning quick fixes into reusable engineering writeups

## Elsewhere

This site is published with GitHub Pages and kept intentionally lightweight so the writing stays easy to maintain.
